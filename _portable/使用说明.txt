灵梦御所下载器 · 便携源码版
================================

本包是**源码 + 一键启动脚本**（不含 exe），适合：
  · 想随时让 AI 帮忙修 bug / 改功能
  · 不想用打包好的 exe

如果你只想直接用，请下载同目录的 lmys-downloader.exe，双击即用，无需装 Python。


【先装 Python（仅第一次）】
1. 到 https://www.python.org/downloads/ 下载 Python 3.9 或更高版本
2. 安装时**务必勾选** "Add Python to PATH"（很重要）
3. 装完可以打开命令提示符输入 python --version 验证


【启动】
双击 启动.bat

脚本会自动：
  · 检查 Python 是否可用
  · 首次运行自动安装依赖（flask / requests / pycryptodome）
  · 启动服务并打开浏览器

窗口**不要关**（关了服务就停了）。想停止服务，关掉那个黑窗口即可。


【使用】
1. 浏览器会自动打开 http://127.0.0.1:8765
2. 输入资源代码（如 R1725 / A0038 / S1000）→ 点「解析」
3. 点「下载到本机」

建议先点右上角「⚙️ 设置」：
  · 默认下载目录 —— 改到空间大的盘（别用系统盘）
  · MEGA 代理地址 —— 打不开 MEGA 时填（如 http://127.0.0.1:7890），能直连就留空
  · 同时下载的文件数 / 限速 —— 按需
改完保存立即生效，不用重启。


【支持哪些代码】
    R  独立资源      S  投稿资源      Y  女性向
    M  音乐合集      P  图包/壁纸     C  同人志打包
    A  抢先发布      MS 魔穗字幕组    YY 夜桜字幕组
    数字后带 a       全年龄版本（如 A0038a，输入 A0038 也能查到）
    纯数字           早期旧资源

老代码（云端库没收录的）会自动：
  · 去官网找简介和封面图
  · 去 MEGA 存档（2024-04 宕机恢复存档）找下载链接


【下载相关】
- 保留 MEGA 里的文件夹结构
- 已存在的文件自动跳过（不重复下载），界面标绿「已有」
- 断点续传（.part 文件），中断后重新开始会接着下
- 任务可折叠（点任务行），右键任务行 / 文件行有不同菜单
- MEGA 匿名下载有配额（约 5~10GB / 6 小时，按 IP），超了需等待或换代理


【遇到 bug 怎么办】
把本目录整个（或 src 文件夹）发给 AI，然后说明：
    1. 你做了什么操作
    2. 期望是什么
    3. 实际出现了什么（有截图更好）
（若用的是 exe 版，把同目录的 reimu.log 运行日志也一并提供，能帮 AI 快速定位）

AI 改完源码后，直接再双击 启动.bat 即可生效（不用重新打包）。

如果想打包成 exe 发给别人：
    pip install pyinstaller
    cd src
    pyinstaller lmys-downloader.spec --noconfirm --clean
    产物在 src/dist/lmys-downloader.exe
