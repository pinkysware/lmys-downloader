灵梦御所下载器 · 便携版
================================

【快速开始】
1. 双击 lmys-downloader.exe
2. 浏览器会自动打开 http://127.0.0.1:8765
3. 输入资源代码（如 R1725 / A0038 / S1000）→ 点「解析」
4. 点「下载到本机」

首次启动会自动从云端拉取资源数据（约 4MB），稍等几秒即可。


【建议先做的设置】
点页面右上角的「⚙️ 设置」：

- 默认下载目录
    资源会下载到「该目录 / <代码> / 」下，并保留原有子目录结构。
    强烈建议改到空间大的盘（比如 D:\downloads），别用系统盘。

- MEGA 代理地址
    能直接访问 MEGA 就留空；
    打不开 / 一直报错时，填你的代理，如 http://127.0.0.1:7890
    （填完保存，不用重启，立即生效）

- 同时下载的文件数（默认 3）
- 下载限速（KB/s，0=不限；填 1024 就是 1 MB/s）


【支持哪些代码】
御所的代码不止 R 和 S，全部支持：
    R  独立资源      S  投稿资源      Y  女性向
    M  音乐合集      P  图包/壁纸     C  同人志打包
    A  抢先发布      MS 魔穗字幕组    YY 夜桜字幕组
    数字后带 a       全年龄版本（如 A0038a，输入 A0038 也能查到）
    纯数字           早期旧资源

老代码（云端库没收录的）会自动：
    · 去官网找简介和封面图
    · 去 MEGA 存档（2024-04 宕机恢复存档）找下载链接


【下载相关的小知识】
- 会保留 MEGA 里的文件夹结构
- 已经存在的文件会自动跳过（不重复下载），列表里标绿「已有」
- 支持断点续传（.part 文件），中断后重新开始会接着下
- 任务可以折叠（点任务行），右键任务行/文件行有不同菜单
- MEGA 匿名下载有配额限制（大约 5-10GB / 6 小时，按 IP 算）
  超了会提示等待，或换个代理出口


【遇到 bug 怎么办】
把本目录下的 src 文件夹整个发给 AI（ChatGPT / Claude / 通义千问等都行），
然后描述：
    1. 你做了什么操作
    2. 期望是什么
    3. 实际出现了什么（有截图更好）

AI 改完源码后这样运行：
    pip install -r src/requirements.txt
    cd src
    python lmys_web.py
（需要先装 Python 3.9+）

如果想直接改 exe，让 AI 改完源码后重新打包：
    pip install pyinstaller
    cd src
    pyinstaller lmys-downloader.spec --noconfirm --clean
打包好的 exe 在 dist/ 目录。


【目录说明】
    lmys-downloader.exe    主程序，双击运行
    src/                   源码（出问题时发给 AI）
    使用说明.txt            本文件
    reimu.log             运行日志（出问题时一并提供，很有帮助）
