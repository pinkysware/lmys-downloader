# 灵梦御所下载器 (Reimu Downloader)

一个浏览器访问的 Web 下载工具：输入灵梦御所的资源代码（如 `R4191`、`S5271`），
查询该资源的 MEGA / 磁力 / 百度网盘等下载链接，并把 MEGA 资源直接下载到本机。

> 数据源为云端预抓的 reimu-warehouse 静态库，查询代码**无需配置任何 Telegram 凭据**，开箱即用。

## 功能特性

- 🌐 **纯浏览器操作**：本机 `http://127.0.0.1:8765` 访问，电脑/手机/平板都能用
- 🔍 **即查即用**：输入代码 → 从云端预抓库秒回（覆盖 R2xxx~R44xx、S4xxx~S52xx，共 1700+ 条）
- ⬇️ **MEGA 直连下载**：服务端流式下载 + AES 解密，带断点续传（.part）、进度、子目录还原
- 📊 **实时进度**：每个文件的速度 / 剩余时间 / 进度条
- 📁 **文件级操作**：右键暂停 / 继续 / 取消 / 查看连接 / 打开目录 / 优先级
- 🗂️ **目录浏览器**：网页内浏览服务器磁盘，自选保存位置，支持新建文件夹
- 🔁 **任务持久化**：刷新 / 重启服务任务不丢，.part 可续传

## 工作原理

本工具**查询代码不再实时连 Telegram**，而是使用云端 reimu-warehouse 的预抓数据（`data.json`），
该数据由 GitHub Actions 每天自动同步新投稿。你只需下载 MEGA 文件时保持本机运行。

代码规则：

| 代码前缀 | 内容 | 说明 |
|---|---|---|
| `Rxxxx` | MEGA 资源 | 动画/游戏/同人，通常单文件或文件夹，MEGA 直链 |
| `Sxxxx` | 多网盘资源 | 磁力 / 百度盘 / TeraBox 等多源（也可能含 MEGA） |

- `R` 开头：WebUI 直接流式下载到本机
- `S` 开头 / 磁力 / 百度盘：返回链接，在你当前设备点开，系统唤起对应 App

> 注意：云端库覆盖约 2026 年至今的投稿。更早的历史代码（如需考古）不在范围内。

## 环境要求

- Python 3.9+
- 能访问 MEGA（下载时；国内网络可能需要代理，见下）

## 安装

```bash
git clone <你的仓库地址>
cd reimu-downloader
pip install -r requirements.txt
```

## 启动

```bash
python lmys_web.py
# 指定端口：python lmys_web.py --port 8765
# 局域网访问：python lmys_web.py --host 0.0.0.0
```

首次启动会自动从云端拉取数据缓存（约 3.7MB）。浏览器打开 http://127.0.0.1:8765。

**无 Telegram 凭据要求**——直接输入代码即可查询。

## 使用

1. 在顶部输入框输入代码，如 `R4191` → 点「解析」
2. 会显示下载链接 + 提取码 + 简介；点「下载到本机」进入下载
3. 下载区选择保存目录（网页内目录浏览器）→ 确定
4. 下方任务区实时显示进度

下载目录默认在你用户主目录下的 `VRGAME/`，可用环境变量 `REIMU_SAVE_DIR` 改。

云端数据源默认 `https://reimu-warehouse.pages.dev/data.json`，可用环境变量 `WAREHOUSE_DATA_URL` 覆盖。

## MEGA 下载代理

MEGA API 默认直连。如果你的网络访问 MEGA 需要代理，设环境变量 `MEGA_PROXY`：

```bash
export MEGA_PROXY=http://127.0.0.1:7892   # 你的代理地址
```

## 常见问题

**Q: 提示"云端资源加载失败"？**
启动时从 reimu-warehouse.pages.dev 拉取数据失败。检查网络能否访问该地址，或稍后重试。
（也可手动在页面点「刷新数据」重新拉取。）

**Q: 搜到某代码但显示无下载链接？**
该资源可能只有简介没有可下载链接，或数据未完整同步。

**Q: 某代码提示未找到？**
云端库只覆盖部分代码。可能是较新的投稿尚未同步（等云端每天自动更新），或该代码不在灵梦御所仓库。

**Q: MEGA 下载慢 / 报 509？**
MEGA 匿名下载有配额（约 5-10GB/6小时，按 IP）。等配额恢复或设代理换出口 IP。
