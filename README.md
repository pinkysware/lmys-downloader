# lmys-downloader

灵梦御所资源下载工具：输入资源代码（如 `R4191`、`A0038`、`S5271`），查询资源的简介、封面与下载链接，并把 MEGA 资源直接下载到本机。

数据源为云端预抓的静态资源库，查询即查即用、开箱即用。

## 功能特性

- **纯浏览器操作**：本机 `http://127.0.0.1:8765` 访问，电脑 / 手机 / 平板都能用
- **全类型代码支持**：R / S / Y / M / P / C / A / MS / YY / 纯数字，以及 `a` 后缀（全年龄）
- **老代码兜底**：云端库未收录的代码，自动去官网找简介封面 + 去 MEGA 存档找下载链接
- **MEGA 直连下载**：流式下载 + AES 解密，断点续传（.part）、保留子目录结构
- **跳过已有文件**：下载前检测已存在的完整文件，直接跳过（列表标绿「已有」）
- **任务折叠 + 实时进度**：任务行显示合计大小 / 进度 / 速度 / 剩余时间，可展开看文件明细
- **右键菜单**：任务级（全部暂停 / 继续 / 取消 / 移除 / 删除磁盘文件）与文件级（暂停 / 优先级 / 查看连接 / 删除）分开
- **设置面板**：下载目录、MEGA 代理、并发数、限速，改完即时生效
- **任务持久化**：刷新 / 重启服务任务不丢，.part 可续传

## 代码规则

| 前缀 | 含义 | 前缀 | 含义 |
|---|---|---|---|
| `R` | 独立资源 | `A` | 抢先发布 |
| `S` | 投稿资源 | `MS` | 魔穗字幕组 |
| `Y` | 女性向 | `YY` | 夜桜字幕组 |
| `M` | 音乐合集 | 数字后 `a` | 全年龄版本 |
| `P` | 图包 / 壁纸 | 纯数字 | 早期旧资源 |
| `C` | 同人志打包 | | |

- `R` / `A` 等 MEGA 资源：WebUI 直接流式下载到本机
- 磁力 / 百度盘等多网盘资源：返回链接，在你当前设备点开

## 运行方式

### 方式一：直接用 exe（推荐给普通用户）

下载 Release 里的 `lmys-downloader.exe`，双击即用，**无需安装 Python**。

### 方式二：便携源码包（适合改 bug / 二次开发）

下载 Release 里的 `lmys-downloader-portable.zip`（约 160KB，仅源码 + 启动脚本），解压后：

1. 先装 [Python 3.9+](https://www.python.org/downloads/)（安装时勾选 **Add Python to PATH**）
2. **双击 `启动.bat`** —— 会自动装依赖并启动，浏览器自动打开

出问题时把 `src/` 目录发给 AI（说明操作和现象），改完**再双击 bat 即可生效**，无需重新打包。

### 方式三：手动源码运行

```bash
pip install -r requirements.txt
python lmys_web.py
# 指定端口：python lmys_web.py --port 8765
# 局域网访问：python lmys_web.py --host 0.0.0.0
```

首次启动会自动从云端拉取数据缓存（约 4MB）。浏览器打开 <http://127.0.0.1:8765>。

### 自行打包 exe

```bash
pip install pyinstaller
pyinstaller lmys-downloader.spec --noconfirm --clean
# 产物在 dist/lmys-downloader.exe
```

## 设置说明

页面右上角「⚙️ 设置」：

| 项目 | 说明 |
|---|---|
| 默认下载目录 | 资源下载到「该目录 / <代码> /」下，保留原有子目录结构 |
| MEGA 代理地址 | 留空=直连；访问 MEGA 需要代理时填，如 `http://127.0.0.1:7890`（改完即时生效，无需重启） |
| 同时下载的文件数 | 1~16，默认 3 |
| 下载限速 | KB/s，0 = 不限速 |

也可用环境变量：`REIMU_SAVE_DIR`（下载目录）、`MEGA_PROXY`（代理）、`WAREHOUSE_DATA_URL`（数据源）。

## 常见问题

**Q: 提示「解析失败 / MEGA 请求失败」？**
多半是网络到 MEGA 不通。在设置里填上可用的代理（本机 Clash 一般是 `http://127.0.0.1:7890` 或 `7892`）。

**Q: 代码搜不到？**
云端库只覆盖部分代码。更早的代码会自动去官网与 MEGA 存档查；若都没有，说明确实未收录。

**Q: 下载很慢 / 报 509？**
MEGA 匿名下载有配额（约 5~10GB / 6 小时，按 IP 计算）。等配额恢复，或换代理出口 IP。

**Q: 想重新下载某资源？**
若文件还在磁盘上，点下载会提示「已下载完成」并复用任务；想重下就先删掉文件（或右键任务「移除任务并删磁盘文件」）再点。

**Q: 界面出问题了怎么办？**
把 `src/` 目录连同现象描述发给 AI 即可让它帮忙修改；改完用 `python lmys_web.py` 直接跑，或按上面的方式重新打包 exe。
